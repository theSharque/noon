# Полдень 21 века

Браузерная космическая MMORTS — [21noon.com](https://21noon.com).

Игра живёт с середины 2000-х: сначала Flash, потом долгие годы без нормального клиента.
В 2019 код переехал из SVN в git, а в 2026 я решил её реанимировать — поднять сервер,
убрать мусор и дать новый HTML-клиент вместо умершего Flash.

Это не переписывание с нуля и не «современный продукт». Это старая любимая игра,
которую хочется снова увидеть живой.
